---
title: "Request Money Transfer"
api: "POST https://api.nolimittopup.com/api/ThaiLan/CustomerTicketByThaiLan/request-money"
description: "Transfer money from one advertising account to another."
---

<Note>
  The ad account that initiates the transfer (`oldAd`) will be revoked when the request is granted.
</Note>

### Body Parameters

<ParamField body="oldAd" type="long" required>
  The source ad account ID (will be revoked).
</ParamField>

<ParamField body="newAd" type="long" required>
  The destination ad account ID receiving the funds.
</ParamField>

<ParamField body="accountIdThai" type="string">
  Optional Thai account reference identifier.
</ParamField>

<ParamField body="callbackUrl" type="string">
  Optional Webhook callback URL.
</ParamField>
