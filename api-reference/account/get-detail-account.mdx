### Headers

<ParamField header="API_KEY" type="string" required>
  Your active API Key.
</ParamField>

### Path Parameters

<ParamField path="id" type="long" required>
  The unique identifier for the customer ticket you wish to retrieve.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.nolimittopup.com/api/ThaiLan/CustomerTicketByThaiLan/getdetail/10021" \
  -H "API_KEY: {{YOUR_API_KEY}}"
```
</RequestExample>
