# ThaiLan Enterprise API

The **ThaiLan API** (`api.nolimittopup.com`) enables programmatic management of Facebook Advertising Accounts, real-time balance checks, instant top-ups, account refunds, credit lines/loans, debt settlement proofs, and automated webhook callbacks.

## Core Capabilities

<CardGroup cols={2}>
  <Card title="Account Provisioning" icon="ticket">
    Request new Facebook ad accounts, view ticket approvals, and manage refunds.
  </Card>
  <Card title="Instant Top-Ups" icon="money-bill-transfer">
    Create top-up orders with detailed execution logs and receipt statements.
  </Card>
  <Card title="Live Balance Monitoring" icon="chart-line">
    Batch check balances for multiple Facebook Ads IDs or fetch all active ads.
  </Card>
  <Card title="Callback Webhooks" icon="webhook">
    Receive real-time asynchronous notifications upon ticket processing.
  </Card>
</CardGroup>
